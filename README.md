# Method Overloading in Java

## Description
This project demonstrates method overloading in Java using a `Calculator` class. It defines multiple `add()` methods with different parameter lists to calculate the sum of two and three numbers.

## Features
- Accepts three integer inputs from the user.
- Calculates the sum of two numbers.
- Calculates the sum of three numbers.
- Demonstrates method overloading.
- Uses a private method to calculate the sum of three numbers.

## Concepts Used
- Java Classes and Objects
- Method Overloading
- Static Nested Classes
- Access Modifiers (`public` and `private`)
- User Input using `Scanner`

## Technologies Used
- Java
- JDK

## How to Run
1. Save the source code as `MethodOverloading.java`.
2. Open a terminal in the file's directory.
3. Compile the program:

   ```bash
   javac MethodOverloading.java
   ```

4. Run the program:

   ```bash
   java MethodOverloading
   ```

5. Enter three integer values separated by spaces.

## Example Input
```text
10 20 30
```

## Example Output
```text
Sum of two numbers: 30
Sum of three numbers: 60
```
